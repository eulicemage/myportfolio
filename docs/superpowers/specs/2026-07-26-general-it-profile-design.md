# General IT Profile Design

## Goal

Broaden the portfolio from a software-development-focused presentation to a
general IT profile that supports applications for IT Associate, IT Support, Associate Sofware Engineer, and other IT related roles.

## Content Changes

- Update the hero introduction to describe practical IT experience across
  software development, hardware support, and technical troubleshooting.
- Add a Freelance IT Technician item in the About section. It will state that
  the work is on-call and includes customer software and hardware issue
  resolution, device setup, maintenance, and practical technical support.
- Update the contact copy to welcome general IT opportunities while retaining
  the existing software projects as evidence of technical range.

## Scope

The update is content-only in `src/components/Portfolio.jsx`. Existing layout,
interactions, project data, and contact links remain unchanged.

## Verification

Run the existing production build after the content update to ensure the React
component compiles successfully
